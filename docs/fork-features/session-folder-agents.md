# Session folders pick their agent

A session folder can say which agent its new chats start on. Pick once in
the folder's settings, and every chat created inside starts on that agent.
Upstream folders only group sessions; the folder-to-agent binding is this
fork's.

[Русская версия](#русская-версия)

## What it is for

A review folder always opens on the reviewer; a support folder always opens
on the support agent. You stop re-choosing the agent for every new chat in
a place whose work always wants the same one.

## How it works

- The setting lives in the folder's own menu, beside the agents the app
  offers for a new chat.
- It changes only the **default** for new chats: each chat can still be
  started on, or switched to, any agent.
- Membership is by folder, not by session — moves out of the folder free a
  chat from the default.

# Папка сессий выбирает своего агента

Папка сессий может сказать, на каком агенте начинают её новые чаты.
Выберите один раз в настройках папки — и каждый чат, заведённый внутри,
стартует на этом агенте В апстриме папки только группируют сессии; связь
«папка → агент» — работа этого форка.

[English](#session-folders-pick-their-agent)

## Зачем это

Папка ревью всегда открывается на ревьюере; папка поддержки — на агенте
поддержки. Больше не надо выбирать агента заново для каждого чата в месте,
чья работа всегда хочет одного и того же.

## Как это работает

- Настройка живёт в меню самой папки, рядом с агентами, которые приложение
  предлагает для нового чата.
- Она меняет только **дефолт** для новых чатов: любой чат можно по-прежнему
  завести на любом агенте или переключить на любой.
- Членство — по папке, не по сессии: переезд из папки освобождает чат от
  дефолта.
